## YoukuTV 真机复测 5 个问题的根因定位与修复

用户上一版 IPA 装到 Apple TV 后反馈 5 个问题，本轮逐条定位并修复。

### 根因与修复

| # | 问题 | 真实根因 | 修复 |
|---|---|---|---|
| 2 | 播放报错 | **两个叠加**：① ups 用 JSONP（`mtopjsonp1({...})`），旧代码先 `JSONSerialization` 再剥包装 → 顺序反了，100% 失败；② `URLComponents.queryItems` 不做完整百分号编码，裸 `+` 被服务端当空格 → `FAIL_SYS_ILLEGAL_ACCESS` | 新增 `MTopQuery`（RFC 3986 unreserved 集）；`YoukuUpsClient` 改成先 `stripJSONP` 再 `JSONSerialization` |
| 3 | UI 比例不对 | Info.plist 缺 `UILaunchImages` → tvOS 判定无启动图 → **兼容模式，界面缩到 1/4** | `project.yml` 增加 `UILaunchImages: [{UILaunchImageName: LaunchImage}]` |
| 4 | 缺少首页推荐 | 优酷 SSR `window.__INITIAL_DATA__`；解析坑：括号配平必须区分字符串内外、数据含 JS `undefined`；**拦路虎是阿里 WAF 惩罚页** | 新增 `YoukuSSR` + `YoukuHomeClient` |
| 5 | 缺少历史记录 | 服务端接口需 SecurityGuard native 签名，Swift 不可复现 | 改本机持久化 `YoukuHistoryStore`（UserDefaults，上限 100 条） |

### 关键实测结论

- **阿里 WAF 惩罚页**：`bxpunish: 1` + `_____tmd_____/punish?x5secdata=`，响应体 1397 字节，
  cookie `Max-Age=20` → 惩罚窗口约 20 秒。
  罪魁祸首是**根 URL 会 302 到 `/ku/webhome`**，这条 302 链路触发惩罚；
  **直连 `https://www.youku.com/ku/webhome` 稳定（6/6）**。
  cookie 与 Accept-Language 非必要；频率非主因（0.5s 间隔也行），
  但密集重试会全撞在 20 秒窗口内 → 退避必须拉长到秒级。
- **Swift `Character` 是字素簇**：`"\r\n"` 长度为 1，
  `split(separator: "\n")` 在 CRLF 边界切不开 → 按行拆必须用
  `components(separatedBy: .newlines)`。
- **mtop 原生接口签名墙**：`x-sign` 由 SecurityGuard `libsgmainso` native 层计算，
  Swift 无法复现。`/gw/` 错误漏斗：
  `缺m-pv → 缺m-appkey → 缺m-sign → 请求失效 → FAIL_SYS_ILEGEL_SIGN`。
  业务 appKey `23164371`，authCode 绑定 APK 签名证书。
  → 服务端历史 / TV 原生播放 / 会员内容均走不通。
- TV 原生播放接口逆向结论（未端到端）：`mtop.yunos.videoplay.playurl.getPlayUrlNew`，
  appKey `23669785`，网关 `acs.m.taobao.com`，不需要 ckey；
  `data = {videoId: <数字型 fileId>, systemInfo: <JSON 字符串>}`；
  `numeric = Base64.decode("X"去首字符) >> 2`。
