# Youku TV for Apple TV — 交付说明

> 面向没有编程背景的读者。照着做即可，不需要理解代码。

---

## 一、这东西是干什么的

一个能在 Apple TV 上运行的 App，界面是优酷风格：首页有推荐剧集、可以搜索、点进去能看到剧集列表、点播放能看视频。

**当前完成度**：
- ✅ 首页推荐（真实优酷内容，已验证接口返回真实数据）
- ✅ 搜索（真实优酷内容，已验证）
- ✅ 详情页与剧集列表界面
- ⚠️ 视频播放地址的解析还差最后一步（原因见第五节）

## 二、你需要准备什么

| 东西 | 说明 | 是否必需 |
|---|---|---|
| **Mac** | 必须是 Mac，Apple 的开发工具只跑在 Mac 上 | 必需 |

| Apple TV | 用来实际观看 | 可选（可先用模拟器看界面） |

## 三、五分钟装好 Xcode

1. 打开 Mac 的 **App Store**
2. 搜索 **"Xcode"**，点「获取」→「安装」
3. 安装可能需要 1-3 小时（12GB 下载 + 解压）
4. 装完后**重启 Mac**
5. 打开 Xcode，弹窗提示安装额外组件 → 点「安装」

验证成功：终端里输入 `xcodebuild -version` 会显示版本号。

---

## 四、注册开发者账号

1. 打开 <https://developer.apple.com/account>
2. 用你的 Apple ID 登录，点「Enroll」
3. 选 **Individual**（个人开发者，最快，当天能过）
4. 按提示填资料、绑卡（99 美元/年）
5. 审核通常 **1-3 天**

## 五、把 App 装到你的 iPhone 上（TestFlight）

### 5.1 打开工程

在访达里双击这个文件：

```
YoukuTV/YoukuTV.xcodeproj
```

Xcode 会打开。左边文件树里能看到 `Sources` 文件夹。

### 5.2 配置签名（关键一步）

1. 左边点最上面的蓝色项目图标 **YoukuTV**
2. 中间选 **TARGETS** 下面的 **YoukuTV**
3. 上方 **Signing & Capabilities** 标签
4. 勾上 **Automatically manage signing**
5. **Team** 下拉框选你的名字（如果空的就先登录 Apple ID：菜单栏 Xcode → Settings → Accounts → 加号 → Apple ID）
6. **Bundle Identifier** 改成唯一的，比如 `com.你的名字.youkutv`
   - 必须改！因为 `com.workbuddy.youkutv` 可能被别人注册过
7. 把 tvOS Deployment Target 改成 **16.0** 或更高

### 5.3 跑起来看看（可选，先验证界面）

1. 菜单 **Product → Destination** → 选 **My Mac** 或 **Apple TV**
2. 按 **⌘R** 运行
3. 没 Apple TV 的话，选 **Any iOS Device** 也能编译通过（只是看不到界面）

### 5.4 打包上传

1. 菜单 **Product → Archive**
2. 打包完成后，Xcode 右上角会出现 Organizer 窗口
3. 左边选 **Distribute App** → **App Store Connect** → **Next**
4. 选 **Upload**（注意别选 Export）→ **Next**
5. 填版本号（如 1.0）→ **Upload**
6. 等上传完成

### 5.5 在 App Store Connect 里开启 TestFlight

1. 浏览器打开 <https://appstoreconnect.apple.com>
2. 左侧 **My Apps** → 点你的 App（首次要先点 `+` → **New App**）
   - 名称：随便，比如 Youku TV
   - 平台：**tvOS**
   - Bundle ID：选你刚才设的那个
   - SKU：随便填
3. 左侧点 **TestFlight**
4. **App Information** 填一下（名称、简介、反馈邮箱）
5. 上传完的版本会出现在 **Builds** 区域，点它右边的 `+` 加到 **Internal Testing**（内部测试）
6. 回到 **Internal Testing** 标签 → **Add Members** → 添加你自己的 Apple ID
   - 内部测试最多 100 人，**而且不需要经过苹果审核**，上传完通常 10-30 分钟就能收到邀请邮件
7. iPhone 上打开 **TestFlight** App → 接受邀请 → 点「安装」

## 六、如果报错

| 报错 | 原因 | 解决 |
|---|---|---|
| `No profiles for 'com.xxx.youkutv' found` | Bundle ID 没改成你自己的 | 回到 5.2 步骤 6 |
| `Signing for "YoukuTV" requires a development team` | 没选 Team | 回到 5.2 步骤 5 |
| `Unable to find a destination` | 没选运行目标 | Product → Destination 选一个 |
| `The certificate is not trusted` | Xcode 组件没装全 | Xcode → Settings → Components 里安装 |
| 上传后 TestFlight 收不到 | 内部测试也要等 Apple 处理 | 等 30 分钟，刷新 TestFlight |

## 八、关于视频播放（为什么还差一步）

优酷对"取视频播放地址"这个接口加了设备指纹加密。这套加密代码在原 App 的一个叫 `SecurityGuard` 的系统组件里，
只有真正的安卓设备才能算出结果，纯代码复刻不了（业界普遍如此，不是本次没做好）。

**三个可选方案**：

**方案 A（推荐，最快）**：App 内嵌网页播放器
- 在 App 里放一个网页窗口，直接打开优酷的播放页
- 优点：1-2 小时能搞定，播放一定正常
- 缺点：不是原生播放器界面

**方案 B**：找 H5 侧的播放接口
- H5 播放接口的加密等级比 TV 端低，有可能能直接调通
- 我已经找到并验证了 H5 的搜索接口，播放接口还在找
- 成本：不确定，可能 1 小时也可能 1 天

**方案 C**：只做"节目浏览"应用
- 界面完整，能搜能看封面能看剧集列表，点播放跳转 Safari 打开优酷网页
- 成本：10 分钟
